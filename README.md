# AGRICARE - Smart Farming Platform 🌾

An AI-powered precision agriculture platform built for the **Smart India Hackathon 2026**. 
AGRICARE connects farmers to their IoT sensors, farm robots, and AI predictive models to provide real-time crop insights, yield prediction, and smart advisory.

Currently, this repository contains **Phase 1** of the project: A robust, responsive Frontend built with React, Vite, and TypeScript powered by realistic mock data.

## 🚀 How to Run Locally

If you want to run this project on your own computer, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer. (We recommend the LTS version).

### Step 1: Clone the Repository
Open your terminal or command prompt and run:
```bash
git clone https://github.com/iamsanjayp/FarmGaurdian.git
```

### Step 2: Navigate to the Project Folder
```bash
cd FarmGaurdian
```
*(Note: Ensure you are in the correct directory. If you cloned it into a folder with a different name, use that name instead).*

### Step 3: Install Dependencies
Install all the required packages by running:
```bash
npm install
```

### Step 4: Start the Development Server
Once the installation is complete, start the local server:
```bash
npm run dev
```

### Step 5: View the App
Your terminal will show a local URL (usually `http://localhost:5173`). Open that URL in your web browser to see the application running!
